# 总控区维护规则

- 只允许 `manager` 对话修改本目录。
- 发布记录只追加勘误，不删除历史。
- APK 与 bundle 保存在本机但不进入 Git；发布清单必须记录其 SHA-256。
- 签名密钥和密码不得写入任何被 Git 跟踪的文件。
- 构建必须来自干净提交，自动测试、设备测试和用户确认分别记录。
- 对功能对话开放文件时，必须在其 `MANAGER_LINK.md` 或跨对话消息中列出精确路径。
- 派工前按 `REPORTING_PROTOCOL.md` 写好回复规则；完成交接后等待主动报告，不反复轮询或催促。跨项目仅联系对方管理员。
- 核验按根 `AGENTS.md` 的证据复用规则执行；已有清晰交接证据的事项不再重复核验，仅补新增、失败或缺失的范围。
- 记录尽量引用已有正文；Markdown 删除/合并不确定项只写入本目录 `README.md` 候选清单，等用户明确同意后处理。
