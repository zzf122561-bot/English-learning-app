## 固定公共契约

将唯一入口以向后兼容方式扩展为：

```kotlin
@Composable
fun WordMemoryFeature(
    onLookupRequested: (String) -> Unit = {}
)
```

- 默认空回调必须保持原有调用方可直接使用 `WordMemoryFeature()`。
- 回调参数只能是普通 `String`，不得依赖或读取词典模块类型。
- 模块只发出查词请求，不创建词典页面、不持有根App导航。

## 长按取词行为

- 在功能1学习文章的英文文本中长按某个单词时，计算该触点所在完整英文词并调用回调一次。
- 单词字符只接受 Unicode Latin 字母；ASCII `'`、弯撇号 `’` 和连字符 `-` 仅在左右都是 Latin 字母时属于词内字符。
- 长按空白、中文、数字或纯标点不触发；单词首尾不得包含撇号或连字符。
- 传给回调的字符串保留页面原始大小写与字符，不在功能1内转小写。
- 不增加选择菜单、弹窗或内部返回栈；根App后续负责打开 `QUICK_LOOKUP`。
- 必须保持现有逐段中文显隐、目标强调、默写、滚动/学习位置、字号和其他点击/长按行为；返回词典后原页面位置由原有状态继续保存。

## 实现和测试门槛

- 将“触点偏移→完整Latin单词”的规则提取为功能1内部纯函数，避免把边界逻辑散在Compose手势代码中。
- 手势实现使用文本布局偏移，不能按坐标猜字符宽度；重组时不得重复触发回调。
- 单元测试至少覆盖：普通词、大小写、单引号、弯撇号、连字符、词首尾标点、空白、中文、数字、纯标点、字符串首尾和越界偏移。
- 保留现有7项JVM测试、androidTest源码编译和Room 1→2迁移保护；数据库名、版本、schema与迁移不得变化。
- 强制运行模块测试、Android测试源码编译和AAR构建；确认无APK、无Activity/launcher、无功能2依赖。
- 当前没有Android设备，只能声明源码编译与自动测试，不得宣称长按手势或返回位置已在实机通过。
