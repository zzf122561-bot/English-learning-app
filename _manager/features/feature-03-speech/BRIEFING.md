### 存储：可删、成功替换、回收而不误删

- 区分生成缓存身份与保留身份。保留身份至少为稳定documentId+FULL/PARAGRAPH/SENTENCE+段索引+句子选区标识；同一逻辑范围即使改音色/指令/seed/请求ID也只保留最新成功的一份。不同文章或不同段不能因文本相同被误覆盖。正文hash/参数仍用于判断音频是否匹配当前正文与设置，标题重命名不新建保留身份。
- 第一次生成/明确重新生成使用staging；新音频及报告完整校验并原子提交、切换最新索引后，才清理该范围旧版本。失败、取消、截断、空间不足或进程死亡不能先删旧成功版本，也不能把部分音频标最新完整成功。崩溃恢复可以重试未完成回收，不把重复目录永久遗留。
- 删除生成项目需用户确认，明确删除音频而非文章/模型；删除对应父报告/音频、缓存索引和仅它拥有的无引用子片段，不能只从UI隐藏。旧导出到SAF的用户文件不自动删除。当前播放/导出/生成引用需先停止或等待释放，不能边用边删；清理严格限制本模块私有results/cache-index，拒绝越界/符号链接路径。
- 全文及其子片段的引用关系必须可追踪。替换/删除整篇结果时回收不再引用的旧子片段；重用或共享片段不能被其他记录误删。避免保留每次合成的重复WAV，说明仍有父/子双存时的必要原因及回收边界。

## 稳定宿主契约（先按此实现，发现真实问题一次报告）

```kotlin
enum class SpeechReadingScope { FULL, PARAGRAPH, SENTENCE }
data class SpeechReadingRequest(
    val requestId: String,
    val title: String,
    val englishParagraphs: List<String>,
    val scope: SpeechReadingScope,
    val paragraphIndex: Int? = null,
    val sentenceText: String? = null
)
@Composable
fun SpeechFeature(
    request: SpeechReadingRequest? = null,
    onClose: () -> Unit = {}
)
```

- request=null为独立“语音”页，可编辑/粘贴英文，自行选择全文、段落、句子并生成/播放；不能只显示实验诊断面板。

- 正式页收到文章请求先显示选择范围/文本/设置及生成按钮，不突然耗费数分钟。支持生成后保存/重播、停止、播放暂停/继续及逐段/逐句选择；全文长文用受限串行分段执行而非一次塞超长上下文。准确保持英文顺序、范围与段落/句子标识，显示完成/当前/待执行；取消后不继续队列，截断不得报完整成功。
