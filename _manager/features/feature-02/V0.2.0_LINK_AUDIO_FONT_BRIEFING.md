## 1. 词条内锚点

- 只放行当前受控词条文档内的同文档 `#fragment` 定位，包括安全的百分号编码片段。
- 放行后由WebView在当前文档滚动；不得替换查询、创建模块内返回栈或触发网络主文档请求。
- 现有受控跨词条查询继续只走 `https://dictionary.local/lookup?q=...` 内部回调。
- 外部HTTP/HTTPS页面、`javascript:`、`file:`、`content:`、data子框架、受控host非法路径、路径穿越和把MDD资源当主框架继续阻止。
- 不得启用JavaScript、文件访问、内容访问或JS Bridge，也不得为修复锚点放宽 `shouldInterceptRequest` 的主文档/子资源分类。

建议把同文档锚点作为独立、纯JVM可测试的导航决策；只有精确受控base文档加非空安全fragment可以交给WebView处理。

## 2. 两个发音入口

- 顶部蓝色发音按钮继续使用当前所选词条的候选音源。
- 词条正文中可识别的发音链接必须改写成受控的应用内部“播放动作”，由WebView客户端拦截并回调现有发音协调器；不得把音频资源或外部URL作为网页打开。
- 固定顺序：当前词条明确引用的MDD音频 → 当前词条明确引用的严格HTTPS音频 → Android英语TTS。
- 点击正文某个明确音源时，该候选在同来源层内优先，其余当前词条候选作为后备，最后仍可回退TTS。
- MDD路径必须经过既有安全规范化；HTTPS必须维持现有协议、重定向、MIME、大小和临时文件限制。
- 新播放取消旧播放；旧MediaPlayer/TTS回调不得完成新请求；失败需要给用户可理解提示。
- 当前两套已登记MDD的兼容审计没有发现音频资源。没有命中MDD时必须如实回退，不能把TTS或网络音频记录为“MDD原声”。

## 3. 词典管理页逐词典正文字号

- 查词页面不增加字号按钮。
- 在词典管理页每本词典卡片增加 `正文字号：<档位>` 设置项；内置、导入、启用和停用词典均可设置。
- 点击打开目标词典专属对话框，包含十档滑杆、减小/增大、示例文字、`恢复默认`、`取消`、`保存`。
- 只有 `保存` 提交持久化；`取消` 不修改原值；`恢复默认` 只把对话框候选值设为5，仍需保存。
- 档位固定为1–10，默认5；WebView `textZoom` 百分比固定为：`71, 82, 88, 94, 100, 112, 124, 135, 153, 176`。
- 只缩放词条WebView正文。搜索框、词头、词典标签、管理页、功能1均不缩放。
- FULL与QUICK_LOOKUP使用同一本词典的同一档位；切换词典后立即应用目标词典档位；重启后保留。
- 删除导入词典时设置随词典行级联消失；重新导入按默认5创建。
