# App 发布规则

1. 功能对话只提交“可集成”汇报，不构建 APK。
2. 总控从干净提交运行模块测试、边界检查和 App 构建。
3. 测试 APK 命名为 `EnglishApp-v<版本>-test.<序号>-<短提交号>.apk`，归档后不得覆盖。
4. 每份清单必须记录来源提交、App/功能版本、文件名、大小、SHA-256、签名指纹和三层验收状态。
5. 用户确认后提升同一二进制为正式版本，不重新生成不同 APK，并创建 `app-v<版本>` 标签。
6. APK、密钥和 bundle 不进入 Git；清单和哈希进入 Git。
7. 每个发给用户的测试 APK 必须有独立 `ACCEPTANCE.md`；安装证据、设备操作结果和用户确认分别填写，不得相互代替。
