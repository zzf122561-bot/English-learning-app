# 独立语音0.5.0 test.001手机验证

当前只完成构建、签名和实际APK校验。天玑9400/Android16的音频、内存、温度与测速结果均待用户执行。

1. 覆盖安装“本地模型验证”0.5.0-probe/code2。保留旧数据；该包与saber独立，不在两个App中同时运行推理进行比较。
2. 先输入1–2句完整英文，长度不超过400码点；默认68词样例可能超限，手动选择完整短句，不把一半单词当样例。用当前默认声音/配置生成并试听一次，确认完整、清晰、无异常重复，再做耗时对照。
3. 在诊断区点击“同段4 / 6 / 8线程对照”，阅读提示后点“开始测试”。此项会实际执行六次合成，可能耗时数分钟；为可比较，保持同一输入、音色和设备状态，不同时跑另一生成任务。
4. 查看每组实际线程数、冷/暖状态、总耗时/RTF、加载与各合成阶段、内存、温度及热状态。冷启动仅模型重载；报告不代表清空系统文件缓存。字段为空表示无法取得，不能记成零。
5. 失败或主动取消后应停止剩余对照，已测结果可导出JSON，不能把部分报告标为六次全部成功。先保存报告再继续，不覆盖旧诊断。
6. 导出本轮对照JSON，另保留异常试听对应的JSON/WAV。提交手机型号/系统、版本/test号、设置与实际结果给总控，用于选择线程或下一条模型路线。
