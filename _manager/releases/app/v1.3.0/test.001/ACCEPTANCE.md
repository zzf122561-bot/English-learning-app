# saber 1.3.0 test.001 设备验收

当前：自动集成/签名/资产检查通过；**以下设备项全部待用户执行**。目标手机：16GB内存、512GB存储、Android16、天玑9400。没有连接设备，不把源码/编译/模拟状态机当成手机结果。

## 安装与最小验证

1. 覆盖安装同包名1.3.0/code8，不卸载旧App。确认原笔记本、显隐、默写、位置、字号及词典还在。通知权限按系统提示允许；拒绝通知也不得导致崩溃，生成的可见性需另测。
2. 先用2–3个自然段。确认“播放本段”与中文显隐并列、顶部“播放全文”，窄屏/大字下不挤压正文；已有音频可直接播放。切本段停止另一段，本段结束即停，暂停/继续状态正确。
3. 缺段先提示；取消不开始推理。“生成全文”只生成。补齐并播放等待缺段，不跳段；仅播放已有内容明确显示实际段号。暂停后后续生成完成不能突然出声。
4. 生成和播放分别控制。切词典/语音/其他文章、Home、锁屏后，通知进度继续；播放通知/锁屏控制、音频焦点及拔耳机暂停正确。回原文保留位置。
5. 后台生成期间中断进程，再打开：已完成音频仍在，仅继续未完成部分，不自动播放。用户主动暂停/取消后重新打开不得自动续生成。系统强停/重启期间本来就不会持续计算。

## 少量验证通过后再测长文与保护

- 118段文章按自然段逐个完成；“已完成43/118，正在44”时中断，前43段可播放，重开从未完成部分继续。长时服务受系统共享额度影响，不能要求必然连续350分钟。
- 同一段再次生成成功后只保留最新成功版；失败保留旧音频；播放/导出引用中的文件不能被过早删掉。暂停/取消生成不等于删除已完成音频。
- 磁盘不足、损坏文件、保存中中断、重复提交、删除并发：清晰报错，不冒称成功，不损坏旧成功结果。无法安全构造的手机故障不擅自清空用户数据验证。
- 全文列表顺序、缺段等待、跳段提示、导出WAV完整性与真实听感；新全文不重复永久保存一份拼接音频。
- 设置保存只影响新任务，任务详情显示冻结设置；播放倍速不要求重新生成。普通数字应朗读、学习编号不朗读。
- 用共享Skill产物导入App，核对标题/中英段/目标/去编号；自动合成fixture通过不替代此设备链路。
