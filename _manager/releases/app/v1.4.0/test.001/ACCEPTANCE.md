# saber 1.4.0 test.001 设备验收

当前：自动集成、签名和实际产物校验通过；**以下手机项目均待用户执行**。目标为天玑9400、16GB内存、512GB存储、Android16。没有连接设备，不把Android测试源码编译当作界面或播放实测。

## 先验证布局与已有音频

1. 覆盖安装本候选，不卸载、不清除数据。确认原笔记本、位置、显隐、默写、字号、词典、音频与设置保留。
2. 书架长标题、阅读标题/操作/正文分区明确；“显示/隐藏本段中文”和“播放本段”可达，顶部全文与字号操作可达。系统大字号、窄屏下按钮可换行，不覆盖正文；词典/语音页面与导航颜色一致。
3. 用已有音频点击本段播放，再点紧凑播放器展开。确认文章与实际段号/英文一致，时间持续前进、暂停/继续同步，拖动进度有效，0.5–2倍只影响播放。
4. 展开页“收起”和系统返回回到原阅读位置，音频继续；再次展开沿用同一播放进度。切词典/语音、Home、锁屏后仍可按原后台契约控制播放；通知、耳机/音频焦点行为另测。
5. 本段播放结束即停；全文从第一段按序播放。上一段、下一段、片段列表选择的段号与内容一致；快速连点切换后旧进度拖动不能误作用于新段，不能两个播放器叠加。
6. 缺音频先提示，取消不生成；补齐等待缺段，选择仅已有内容时明确显示跳过的段号。主动暂停后，切段或后续生成完成不能突然自动出声。单句/指定范围生成仍可用。

## 词典、留白与旧行为

- 完整词典与临时查词都检查键盘、状态栏/导航栏留白，无内容被遮住或重复大空白；临时查词一次返回原学习位置。
- 长词头/词典名、大字、启停/排序/字号/删除确认、真实CSS/图片/内部跳转和发音回退保持；界面重新排列不等于放宽既有外部访问边界。
- 中文显隐、默写、字号、滚动保存、长按查词和学习编号去除仍符合旧基线。

## 再验证短句生成与后台

1. 先生成1–2句完整短英文，检查声音完整、正常、无异常重复或截断；再生成第001段与少量连续段。异常时保留同次JSON/WAV及段号，暂不投入全文耗时测试。
2. 同一段新生成成功后替换旧结果，失败保留旧可用音频；正在播放/导出的文件不能提前清理。
3. 后台生成、播放独立暂停；切页面/锁屏不断开已提交任务。系统中断后已有段仍可用，重新打开仅恢复未完成生成，主动暂停/取消不自动续跑，不自动出声。
4. 少量段通过后再试长文与恢复；系统强停/重启期间不承诺持续运算。原1.3.0设备边界继续适用。

速度通过[独立0.5.0测试包](../../../tts-probe/v0.5.0/test.001/ACCEPTANCE.md)采集同文4/6/8线程对照，不能凭构建成功或一次体感宣称提速。
