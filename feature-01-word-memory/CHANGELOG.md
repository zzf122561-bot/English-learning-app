# 功能 1 变更记录

本文件只追加新版本和勘误，不覆盖或删除既有历史。

## 0.1.0 — 2026-08-23

- 建立 Kotlin、Jetpack Compose、Room 本地 Android 应用。
- 实现 DOCX 本地解析、编号配对、事务导入和错误报告。
- 实现笔记本管理、逐段中文显隐、目标强调、默写及学习位置持久化。
- 自动验证：5 项 JVM 测试通过，Debug APK 构建成功；既有签名记录为 v2 校验通过。
- 用户确认：2026-08-23 报告真机测试清单全部正确。

## 0.2.0 — 2026-08-23

- 学习页右上角新增 `Aa` 字号控制，提供 1～10 档即时调节。
- 英文正文、中文正文和默写输入正文同步使用所选字号和行高，其他界面字号不变。
- 字号按笔记本独立保存，新笔记本及旧数据升级后默认第 5 档。
- Room 数据库升级至版本 2，使用显式 1→2 迁移；不使用破坏性迁移。
- 修改字号不更新笔记本的最近编辑时间，避免改变列表排序。
- 新增字号映射、越界、独立保存、关闭重开和迁移数据保留测试。
- 自动验证：7 项 JVM 测试通过，仪器测试源码编译成功，Debug APK 构建和 v2 签名校验通过。
- 设备边界：当前没有连接手机，覆盖安装、迁移运行和字号交互尚待用户验收。
- 用户验收：2026-08-24 用户确认 v0.2.0 已验证可用、无问题；功能 1 当前版本正式纳入受保护基线。

## 管理权调整 — 2026-08-24

- 功能1由独立 Application 改为只提供 `WordMemoryFeature()` 的 Android Library；不改变用户功能和本地数据语义。
- Git、App 版本、签名、APK 与正式发布记录改由总纲对话统一管理。
- 功能对话只负责本模块代码和模块测试，完成重大技术更新后必须主动向总控汇报。

## 0.3.0 — 2026-08-24

- 公共入口向后兼容扩展为 `WordMemoryFeature(onLookupRequested: (String) -> Unit = {})`。
- 英文正文使用文本布局偏移识别长按触点，不按坐标估算字符宽度。
- 新增内部纯函数，按 Unicode Latin 字母边界提取原始单词；单引号、弯撇号和连字符仅在两侧均为 Latin 字母时属于词内字符。
- 空白、中文、数字、纯标点和越界偏移不发出查词请求；回调保留原始大小写与字符。
- 数据库名称、Room 版本 2、schema、迁移和 v0.2.0 已验收学习行为均未变化。
- 自动验证：20 项 JVM 测试通过，0 失败；Android 测试源码编译和 AAR 构建成功；功能目录 APK 数量为 0。
- 设备边界：当前没有 Android 设备，长按手势及从词典返回后的页面位置尚未在实机验证。
- 用户验收：2026-08-24 用户概括确认 v0.3.0 test.002 除功能2两项已知问题外其余均正常；该反馈计入长按查词与返回流程验收，但没有设备型号或逐项证据。

## 0.4.0 — 2026-10-03

- 公共入口向后兼容增加 `onReadingRequested(title, englishParagraphs, paragraphIndex, sentenceText)` 默认空回调。
- 学习页新增全文朗读入口，每个英文段落新增朗读选择，可确认本段或实际分句内容。
- 全文按原文顺序回传全部英文段落；整段使用合法零起始索引；单句必须是该段分句结果中的连续原文片段。
- 英文分句处理常见缩写、小数、句末引号和无结尾标点的末句；空文本、中文、越界索引和非原段句子不发出回调。
- 朗读功能不引入语音枚举、引擎、页面或导航依赖；Room 数据库名称、版本 2、schema 和迁移全部保持不变。
- 自动验证：26 项 JVM 测试通过，0 失败；Android 测试源码编译和 AAR 构建成功；功能目录 APK 数量为 0。
- 设备边界：本轮无实机交互证据，不声称全文/本段/单句点击或语音播放已通过设备验收。

## 0.5.0 — 2026-10-05

- `WordMemoryFeature` 在既有两个参数后追加可空 `readingContent` Composable 槽，旧调用继续有效。
- 有槽时，全文/整段/单句入口只更新同一阅读页的当前范围，不发出 v0.4.0 旧跳页回调；空槽时保留旧行为。
- 宿主槽固定在原学习页底部、不进入正文滚动列表；原 `LazyColumn` 和 `LazyListState` 保留，正文仍占页面主要空间。
- 文章身份稳定为 `word-memory:<notebook.id>`；选区只保存段落索引和句子原文，按笔记本隔离，旋转可恢复。
- 空加载态不绘制槽位；正文变动导致原选区失效时，回退全文并在原页提示，不传递旧句子。
- 未引入语音引擎、模型、文件存储或其他功能内部类型；Room 数据库名称、版本 2、schema 和迁移不变。
- 受影响范围验证：11 项 JVM 测试通过，0 失败（新增内嵌槽 5 项＋受影响的既有朗读选择 6 项）；Android 测试源码编译和 AAR 构建成功；其余 v0.4.0 证据沿用，本轮未重复执行；功能目录 APK 数量为 0。
- 设备边界：本轮无实机证据，不声称原页触摸、旋转恢复、边看边听、生成或播放已通过设备验收。
