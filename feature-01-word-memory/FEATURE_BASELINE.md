# 功能 1 受保护基线

基线版本：`0.1.0`  
基线日期：2026-08-23  
Git 标签：`feature-01-v0.1.0-user-tested`

## 已接受的用户功能

- 使用 Android 系统文件选择器导入 `.docx`，一个 Word 文件形成一本笔记本。
- 应用内管理笔记本：列表、打开、重命名、删除、段数、目标数和上次位置。
- 学习页始终显示英文；中文可按段显示或隐藏并记住状态。
- 每段拥有独立默写框，输入自动保存在本机并在重启后恢复。
- 学习位置自动保存，重新打开笔记本时恢复。
- Word 加粗的“编号. 英文/中文”目标在 App 中继续以加粗和主题色特殊显示。

## DOCX 识别契约

- 一个英文目标段和紧随的 `【中文译文】` 段组成一个学习段。
- 读取 Word 正文段落及文字片段的有效加粗属性，并合并相邻加粗片段。
- 目标项采用“稳定编号＋句点＋内容”；编号是不透明字符串，可为纯数字或字母数字组合。
- 中英文目标严格按完整编号配对，不依赖出现顺序。
- 缺失、重复、无法配对或存在无法识别的加粗内容时，整次导入失败并报告问题。
- 段落数和目标数不写死；失败或取消时不写入残缺笔记本。

## 本地数据契约

- Room 版本 1 保存笔记本、学习段、目标项、中文显隐、默写内容和学习位置。
- 导入使用单个数据库事务；删除笔记本级联删除其学习段和目标。
- 数据只保存在设备本地，不依赖网络或 AI；不保存导入的原始 Word 文件。
