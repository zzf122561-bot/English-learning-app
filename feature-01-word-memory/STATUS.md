## 已完成源码

- Android Library 功能模块：Kotlin、Jetpack Compose、Room；
- 系统文件选择器仅接收 `.docx`；
- 流式读取 DOCX 压缩包与正文 XML，不依赖云端和 AI；
- 按标题、英文段、紧随的 `【中文译文】` 段建立学习段；
- 合并 Word 拆分的相邻加粗片段，按不透明编号配对中英文；
- 导入错误清单、读取百分比、取消检查、数据库事务写入；
- 本地笔记本库：打开、重命名、删除、段数、目标数、上次位置；
- 学习页：目标强调、逐段中文显隐、独立默写框、自动保存和位置恢复；
- 解析器测试源码：正常文档、漏译、误加粗、大文档、跨语言乱序配对、纯数字与字母数字编号；
- Room 仪器测试源码：事务导入、目标项关系、中文显隐、默写、阅读位置、重命名与级联删除。
- 学习页右上角 `Aa` 十档字号控制，英文、中文和默写输入正文同步调整；
- 每本笔记本独立持久化字号，默认第 5 档，修改字号不改变最近编辑时间；
- Room 数据库 1→2 显式迁移，旧笔记本新增默认字号且不重建数据库；
- 字号映射、独立偏好、关闭重开及数据库迁移测试源码。
- v0.3.0 公共查词回调：`WordMemoryFeature(onLookupRequested: (String) -> Unit = {})`，原无参数调用保持兼容；
- 英文正文基于文本布局偏移处理长按，按 Unicode Latin 边界回传原始单词；
- 长按取词纯函数及普通词、大小写、撇号、连字符、标点、非 Latin 文本和越界测试。
- v0.4.0 公共朗读回调：全文、整段或单句只回传标题、英文段落列表、段落索引和句子原文；
- 学习页提供“全文朗读”和每段“朗读”入口，可在对话框中确认本段或实际分句内容；
- 英文分句处理常见缩写、小数、句末引号和无结尾标点的末句，空文本、中文和越界请求不触发回调。
- v0.5.0 可空 `readingContent` Composable 槽：有槽时在原学习页底部渲染宿主控件，选择全文/整段/单句只更新原页上下文，不调用旧跳页回调；
- 稳定文章身份为 `word-memory:<notebook.id>`；选区只保存段落索引和句子原文，按笔记本隔离、旋转可恢复，正文变动失效时回退全文并提示；
- 原 `LazyColumn` 和 `LazyListState` 保留，正文占剩余主要高度，底部槽不进入滚动列表；空加载态不向槽位传递旧文章。
- v0.5.1 依据已解析 target key/span 构建独立朗读文本，只移除已确认的学习编号及其分隔，保留年份、小数、金额、型号和正常标点；
- 全文、整段和单句使用同一组干净段落，分句在清理后进行；无法确认的 span/key/目标正文会停止交接并显示错误，不猜删。
- 首段界面连线测试源码覆盖：点击第1段范围入口、确认本段后，槽接收 `word-memory:42`、`paragraphIndex=0`及去编号段落，同时原页显示已选范围。

## 0.5.1 用户反馈与根因边界

- 用户报告“朗读打开后实际不能用”，并不是单纯的文案误解。
- 授权截图中底部显示“朗读·第1段”，说明截图时范围状态已到达宿主槽，但这不证明生成、结果保存或播放链成功。
- 功能1可确认的源码根因：v0.5.0 直接将包含 `A0001.` / `1048.` 的 `segment.englishText` 交给回调/槽，因此学习编号会进入语音文本；v0.5.1 已在本模块修正。
- “朗读完全不可用”的最终根因未在本模块确定：尚需总控在集成宿主与语音任务中检查“生成朗读”点击、请求、返回结果及播放状态。
