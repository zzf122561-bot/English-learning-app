# Feature 02 v0.2.1 内部链接兼容审计

日期：2026-08-26

状态：`ready_for_integration / awaiting_manager_build`

## 失败边界与本轮决定

App 1.0.0 test.001 已由用户设备确认词典应用内链接仍失败。总控没有设备日志、具体词条或原始链接标记，因此本功能任务没有伪称复现。

代码层兼容缺口明确存在：v0.2.0 仍把未枚举的受控同源路径、query、fragment 和资源形态归入 blocked/403，并关闭 JavaScript。用户决定不再逐类选择词典内部链接，而是对已进入当前受控词典文档的内部能力默认兼容。

## 真实词典只读结构审计

只读取两套既有授权 MDX/MDD，并通过随机词条结构采样和 MDD 键扩展名统计确认机制。没有输出链接参数、词条正文或大段版权内容。

| 词典 | `entry:` | 相对链接 | 外部 HTTP | 事件属性 | 事件机制 | 内联/外部/MDD脚本 |
|---|---:|---:|---:|---:|---|---|
| Collins | 1307 | 517 | 0 | 0 | 无 | 0 / 0 / 0 |
| Oxford9 | 553 | 524 | 833 | 386 | `onclick` → `className` | 0 / 0 / 0 |

两本词典都实际存在 `entry:` 与相对快捷链接。Oxford9 的词性/释义快捷定位直接依赖内联 `onclick` 修改 DOM `className`，不依赖 MDD 脚本文件；因此启用受控文档 JavaScript 和内联事件是实际兼容需要，不是无条件扩展。

## 取消的内部限制

- 同文档普通、编码、空或超长 fragment 均交给 WebView 原生处理，不再检查片段字符、解码结果或长度。
- 任意 `https://dictionary.local` 同源页面、路径、query、fragment 和 MDD 资源请求均进入当前 WebView/当前 MDD，不再因为未知路径、遍历样式、反斜杠、扩展名或长度返回 403。
- 相对链接、绝对同源链接、`entry:`、`bword:` 与其他词典自定义 scheme 默认作为内部能力处理；自定义 scheme 不会启动外部 App，而是替换当前词条查询。
- DOM 动态生成的同源/fragment/自定义链接使用同一默认策略，不要求预先经过 HTML 静态白名单。
- HTML 重写器支持相对 `<script src>` 指向当前 MDD；受控文档 CSP 允许 `dictionary.local` 脚本和内联词典事件。
- WebView 开启 JavaScript，以支持 Oxford9 已确认的 `onclick/className` 快捷定位。

## 仍保留的应用边界

- 外部 HTTP/HTTPS 页面不会在词典 WebView 中加载，也不新增外部浏览器跳转。
- file/content/intent/android-app、mailto/tel/sms/geo/market 等本地或跨应用访问继续阻止。
- `allowFileAccess`、`allowContentAccess`、file-URL 跨域访问、DOM storage、数据库、多窗口和 JavaScript 自动开窗继续关闭。
- 没有调用 `addJavascriptInterface`，没有 JS Bridge；词典脚本无法取得 Android 对象。
- CSP `default-src 'none'`；图片、样式、脚本、媒体和字体只允许受控 `dictionary.local`，仅样式和脚本允许词典内联内容；外部脚本/网络连接仍被 CSP 与请求策略隔离。
- MDD 资源只能通过当前查询协调器打开的当前词典读取，不映射 App 文件系统；资源 8 MiB 上限、错误、取消与关闭边界未改。
- 发音动作的 MDD 路径与严格 HTTPS 校验、MDD→HTTPS→TTS 顺序完全未改。

## 行为验证

合成 JVM 回归覆盖：

- 普通、编码、空和超长 fragment；
- 相对、绝对同源、不同路径/query/fragment；
- `entry:`、`bword:` 和未枚举词典自定义 scheme；
- DOM 动态链接与 `javascript:`/`onclick`/内联脚本；
- 相对 MDD `.js`、CSS/图片及未知同源资源；
- 受控内部请求不进入 blocked/403；
- 同文档/同源原生处理不调用查询回调，跨词条只调用当前查询替换；
- 外部 HTTP/HTTPS、file/content/intent/android-app 和常见跨应用 scheme 继续 blocked；
- 发音受控动作安全边界保持。

真实词典测试对 Collins 与 Oxford9 分别断言实际 `entry:` 与相对链接存在并继续精确命中；另对 Oxford9 断言 `onclick/className` 机制存在。测试日志仅保留结构计数。
