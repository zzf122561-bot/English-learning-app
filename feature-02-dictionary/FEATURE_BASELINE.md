# 功能 2：词典受保护基线

版本目标：`0.3.0`（2026-11-07 UI 增量；原固定能力继续保留）

## 固定能力

- 两个现有 MDX/MDD 词典随 App 安装包内置。
- 完整词典页支持搜索并按用户排序查询所有已启用词典。
- 功能1可通过公共回调发起单词临时查询；快速查词按一次 Android 返回键回到功能1原页面。
- 词条能够离线显示 MDD 中的 CSS、图片和字体资源。
- 发音顺序固定为：MDD 内置原声、词条 HTTPS 原声、Android 英语 TTS。
- 内置词典只能启用、停用和排序，不能删除。
- 用户可从 Android 本地导入 MDX/MDD，自动配对资源文件；导入词典可删除 App 私有副本。
- 所有导入、复制和数据库登记必须原子完成；失败不得留下半成品。

## v0.3.0 界面基线

- 搜索、词头与发音、词典标签、WebView 正文各自成区；FULL 与 QUICK_LOOKUP 使用相同查询布局。
- 跟随宿主 MaterialTheme，手机留白 16/20dp，宽屏内容居中且不超过 720dp；大字号不强制缩小。
- 管理卡片完整显示长名称，启停、排序、正文字号和删除分区；管理内容可滚动，主要触点至少 48dp。
- WebView 继续保留 v0.2.1 受控内部链接与脚本兼容、词典 CSS 和逐词典字号；本轮只调整外围 Compose 布局。
- 公共签名、一次快速返回、Room 2、解析、导入和发音顺序保持原行为。

## 数据与隔离

- 使用独立数据库 `englishapp_dictionary.db`，不得读取或修改功能1数据库。
- 原始用户词典不得写入 Git、上传网络或被原地修改。
- 功能2不得直接依赖功能1；根 App 壳负责导航和回调连接。

## 首版明确不包含

全文检索、模糊纠错、收藏历史、云同步、在线词典下载、OCR、系统级悬浮查词以及词典内容编辑。
