## 审计范围

本轮只覆盖总控授权的三个增量：受控同文档锚点、正文/顶部发音链、逐词典正文字号与其 Room v1→v2 迁移。未重复审查或改写解析内核，未修改根 App、公共入口签名、导入协议、签名或 APK。

## 同文档锚点与导航边界

- HTML 重写器只把 `<a>` / `<area>` 的非空安全 `#fragment` 规范为受控主文档锚点。
- 导航策略只把精确受控 origin、精确 `/` 路径、无 query、带非空安全 fragment 的 URL 分类为 `SameDocumentAnchor`。
- WebView 客户端对此分类返回“不覆盖”，让当前文档自行滚动；不会调用内部查询回调，也不会创建模块本地返回栈。
- `entry://`、`bword://` 与受支持相对词条链接仍改写到 `/lookup?q=` 并替换当前查询。
- 外部 HTTP/HTTPS、`javascript:`、file/content、data 子框架、外部/非法主框架、非法受控 host/path、遍历路径、MDD 资源主框架和受控动作伪装成子资源均继续阻止。
- JavaScript、文件访问、内容访问、DOM 存储与 WebView bridge 均未启用。

## 发音动作与回退

- 可识别的正文 MDD 或严格 HTTPS 发音链接改写为 `dictionary.local/action/audio` 受控动作；动作参数经过来源、长度、MDD 路径或 HTTPS URL 严格验证。
- WebView 捕获播放动作并回调 ViewModel，绝不把动作当主文档、MDD 子资源或外部导航。
- 顶部蓝色按钮和正文动作都使用当前选中词典、当前词条的候选。正文点击候选只在其来源层内置顶；总来源顺序仍固定为 MDD → 严格 HTTPS → Android 英语 TTS。
- 新请求先取消旧发音 job 并停止活动播放器/TTS；取消继续传播。全部失败时显示用户可读消息。
- 既有 MDD 安全规范化、HTTPS scheme/host/端口/重定向/MIME/8 MiB 流式上限及临时文件清理保持不变。

## 逐词典正文字号与数据库

- 设置入口只位于词典管理页，每本词典显示 `正文字号：<档位>档`；查询页没有 Aa。
- 对话框提供 10 档 slider、减小/增大、样例、恢复默认、取消、保存。恢复默认只把候选设为 5；取消保留原值；只有保存调用持久化。
- 档位 1..10 映射到 WebView `textZoom`：`71,82,88,94,100,112,124,135,153,176`；读写均夹紧范围，默认档位 5。
- 查询结果标签携带其词典自身字号；切换词典即使用对应 `textZoom`，FULL 与 QUICK_LOOKUP 共享同一数据库值。
- 数据库版本为 2；`MIGRATION_1_2` 精确执行：

```sql
ALTER TABLE dictionaries ADD COLUMN fontLevel INTEGER NOT NULL DEFAULT 5
```

- 没有 destructive migration。字号 DAO 更新只写目标 ID 的 `fontLevel`，不修改 `updatedAt`、顺序、启用状态、运行状态或资源行。
- 内置词典重新核验/替换保留现有字号；新导入默认 5；删除导入词典仍由既有外键级联清除整行。
- 已导出 Room v2 schema。真实 v1→v2 Android 测试创建完整 v1 词典/资源行，迁移后核对原字段、资源与默认 5；当前只完成源码编译，因无设备未运行。
