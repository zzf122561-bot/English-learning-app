# 变更记录

## 0.2.0 内嵌候选

- 新增正式SpeechFeature及全文/段落/句子请求契约，保留独立ModelProbeFeature。请求先预览，按ID去重；忙时显式停止后切换，独立页与文章入口保留各自草稿。
- 实现受限长文串行队列、逐片保存/缓存、父子历史与合并WAV；取消/失败/触顶停止后续片段，进程中断前已保存的片段可找回。
- 正式界面提供Ryan/Aiden、生成风格与个性化自然语言要求、完整高级参数、播放倍速、暂停/继续及导出；保留1.7B Q4和用户认可的单次音质基线。
- Library与原生目标降至API29以配合正式App；源码后端/模型/原生取消补丁未改，不提高宿主最低版本。宿主、签名、Git及APK由总控管理。
- 增量测试、精确产物及设备待测项见SOURCE_MANIFEST.md第10节；模块交付不代表正式App发布或全部真机验收。

## 0.1.0 开发中

- 初始化隔离语音验证模块；目标为 Qwen3-TTS 英文离线段落合成与手机性能/听感测试。
- 阶段1B：纳入固定 Qwen/GGML CPU 源子集和许可证；新增全部生成参数的类型化 JNI、精确模型路径约束、requested/effective 快照、单 session 生命周期和原生合作取消补丁。
- 阶段1B新增 arm64/API31 原生 Release Library 构建、参数单元测试、JNI 测试源码和无模型原生契约测试入口；新增 AAR ELF/notice 检查工具。当时的验证范围与限制见 SOURCE_MANIFEST.md 第7节。
- 阶段2：实现公共模型清单、完整SHA256/原子安装、跨控制器租约、任务排他/合作取消、结果事务与设置持久化；删除模型或清缓存索引保留历史。
- 连接中文操作/设置/结果页面与Qwen适配器，开放真实参数、段落/逐句、冷启动/暖运行/有限批次、显式缓存、JNI无模型自检、播放/播放器变速、SAF WAV/JSON导出。保持唯一宿主入口和原生实现不变。
- 保存requested/effective及失败调用实际参数、模型/引擎身份、真实样本时长/RTF和Android采样指标；同一暖运行批次固定解析后的seed。模式、批次、播放速度与生成参数一并保存/恢复。
- 新增阶段2模拟测试与Android存储测试源码；当前为设备验证候选，具体构建证据、资产契约及待测范围见 SOURCE_MANIFEST.md 第8节。本记录不代表App版本发布或设备验收。
